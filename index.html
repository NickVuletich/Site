03 / Local-first software

Keepwise

Local-First Exact Duplicate Review

A local-first macOS photo-review prototype that finds byte-for-byte duplicates using size bucketing and streaming SHA-256. Rust owns filesystem access, hashing, persistence, and safety boundaries. Keepwise stores Libraries, immutable Scan history, duplicate groups, and review decisions in SQLite while keeping source photographs read-only.
